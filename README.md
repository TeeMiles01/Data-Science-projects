## Projects

### 🕸️ [wikipedia-scraper](./wikipedia-scraper)
A Python script that automates the extraction of HTML data from Wikipedia pages.

### 🧮 [calculator-oop](./calculator-oop)
An advanced calculator built with object-oriented programming. Supports basic arithmetic (`+`, `-`, `*`, `/`) plus advanced operations (exponentiation, square root, logarithm), with error handling for invalid operations and non-numeric input. Includes a dictionary-based design that makes it easy to register new operations dynamically.
