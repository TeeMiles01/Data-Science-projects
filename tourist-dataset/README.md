# Pre-process and prepare ( data cleaning and data exploration) of tanzania tourist dataset for the purpose of machine learning model to predict what a tourist will spend when visiting Tanzania 

# Objective 
Your mission is to pre-process and prepare the provided dataset with the aim of developing a machine learning model to predict what a tourist will spend when visiting Tanzania ( you are not required to build the ML yet)

# Dataset description 
The dataset describes 6476 rows of up-to-date information on tourist expenditure collected by the National Bureau of Statistics (NBS) in Tanzania.The dataset was collected to gain a better understanding of the status of the tourism sector and provide an instrument that will enable sector growth.

# 💡 Key Insights
Numeric trip features (nights spent, group size) show only weak correlation with total spending — cost is likely driven more by trip type than trip duration or group size
Spending patterns vary meaningfully across age groups and purpose of visit, suggesting these are stronger levers for understanding (and potentially forecasting) tourist expenditure
A small number of countries account for a disproportionate share of visitors, useful for targeted tourism marketing strategies
